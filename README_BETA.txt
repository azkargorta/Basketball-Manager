BASKETBALL GM — v0.21 BETA
===========================

Esta beta funciona completamente offline una vez cargada/instalada.
Los datos de la partida se guardan en el navegador/dispositivo del jugador.

PC (Windows)
------------
1. Ejecuta JUGAR.bat.
2. Se abrirá en tu navegador.
3. Juega normalmente; el guardado es automático.

MÓVIL
-----
La forma recomendada es abrir la beta desde un enlace HTTPS (GitHub Pages u otro hosting estático).

Android:
- Abre el enlace en Chrome/Edge/Samsung Internet.
- Pulsa "Instalar app" si aparece, o menú del navegador > Instalar aplicación / Añadir a pantalla de inicio.

Apple iPhone/iPad:
- Abre el enlace.
- Pulsa Compartir.
- Elige "Añadir a pantalla de inicio".

Después de instalarla, se abre como una app independiente y los archivos principales quedan disponibles offline.

IMPORTANTE PARA TESTERS
-----------------------
- No borres los datos del navegador si quieres conservar la partida.
- Usa Más > Guardado > Exportar partida antes de actualizar a una nueva beta.
- Si encuentras un error, indica versión, dispositivo, pantalla y pasos para reproducirlo.
