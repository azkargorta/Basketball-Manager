Basketball GM v0.21 Beta
========================

Primera beta preparada para pruebas externas.

Novedades beta:
- PWA instalable desde hosting HTTPS.
- Funciona offline tras la primera carga/instalación.
- Manifest e iconos propios.
- Service worker con caché offline.
- Botón de instalación/ayuda en móvil.
- Informe beta exportable desde Más > Pruebas y feedback.
- Compatibilidad con saves v0.20.

El juego sigue siendo 100% local: no necesita cuenta ni servidor para guardar partidas.
